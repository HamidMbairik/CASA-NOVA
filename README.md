# CASA NOVA — Boutique Hotel

**Brand personality:** Travel, luxury, warmth, architecture.

## Design System

| Token | HEX | RGB |
|---|---|---|
| Primary | `#26352F` | `rgb(38, 53, 47)` |
| Secondary | `#52665D` | `rgb(82, 102, 93)` |
| Background | `#F5F0E8` | `rgb(245, 240, 232)` |
| Surface | `#E6DED2` | `rgb(230, 222, 210)` |
| Text | `#26302D` | `rgb(38, 48, 45)` |
| Muted Text | `#7B7B72` | `rgb(123, 123, 114)` |
| Accent | `#B58B5A` | `rgb(181, 139, 90)` |
| Accent Light | `#D8C3A5` | `rgb(216, 195, 165)` |

## Usage Rules

- Warm ivory + deep olive/green.
- Gold should appear in subtle luxury details.
- **60%** Background/neutral · **30%** Primary/Secondary · **10%** Accent.
